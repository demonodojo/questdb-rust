Dentro de `GROUP BY` no admite `FLOAT`, `DOUBLE` ni `BOOLEAN`. `concat` devuelve `STRING`: un NULL de texto no aporta, un NULL numérico es `null` y un float nulo es `NaN`. `length` devuelve `INT` y usa `-1` para un texto nulo. `lower` y `upper` devuelven `STRING`, o NULL si el texto es NULL. `upper('βeta')` es `ΒETA`. `left` y `right` devuelven `STRING` y cuentan caracteres: un entero negativo recorta por el otro extremo, y un NULL en el texto o en la cuenta deja NULL. `substring` toma un inicio en base 1 y una longitud. Una longitud constante 0 es vacía, un inicio constante que no alcanza el texto es NULL, y una longitud negativa se rechaza. `trim` devuelve `STRING` y solo quita el espacio ASCII ` ` de los dos extremos. Un tabulador se conserva. NULL sigue siendo NULL. `ltrim` y `rtrim` quitan ese espacio solo por la izquierda o por la derecha. `replace` sustituye coincidencias sin solaparse. Un argumento NULL deja NULL, y una búsqueda vacía deja el texto igual. `starts_with` devuelve `BOOLEAN`. Un texto o prefijo NULL es `false`, y un prefijo vacío coincide con cualquier texto no nulo. `strpos` y `position` devuelven `INT`: el índice en base 1, `0` si no está, y NULL si el texto o la búsqueda es NULL. `split_part` devuelve `STRING`. El índice 1 es el primer campo y uno negativo cuenta desde el final. El índice 0 se rechaza. Un campo que no existe es cadena vacía. `to_lowercase` y `to_uppercase` son `lower` y `upper` con otro nombre. `lpad` y `rpad` rellenan hasta un ancho, o recortan. Con dos argumentos el relleno es un espacio. Un ancho negativo es NULL. `rpad` recorta por el final. `quote_ident` deja el texto tal cual si es un identificador y, si no, lo envuelve en comillas dobles duplicando las internas. Una cadena vacía no se entrecomilla. `length_bytes` cuenta bytes UTF-8 y devuelve `-1` si el texto es NULL. Un `SYMBOL` no está admitido. `size_pretty` formatea un entero como tamaño binario con un decimal. Un negativo sale como `-0.0 EiB`. NULL queda NULL. `abs` conserva el tipo entero. Un `BYTE` pasa a `SHORT` y un `FLOAT` a `DOUBLE`. `abs` de `-0.0` es `0.0`. `abs` de un `SHORT` mínimo sigue siendo negativo. `round` devuelve `DOUBLE`. Sin escala, el medio sube hacia +∞. Con escala, el medio se aleja de cero y `-0.0` conserva el signo. Una escala fuera de rango deja NULL. `floor` devuelve `FLOAT` para `BYTE`, `SHORT`, `INT` y `FLOAT`, y `DOUBLE` para `LONG` y `DOUBLE`. `-0.0` conserva el signo. La forma con escala es decimal y queda fuera. `ceil` y `ceiling` usan los mismos tipos. `ceil(1.5)` es `2.0` y `ceil(-1.5)` es `-1.0`. `-0.0` conserva el signo. `sign` conserva el tipo numérico. Un `DOUBLE` de `-0.0` pasa a `0.0`. Un literal NULL sale como el byte `0`. `sqrt` devuelve `DOUBLE`. Un negativo sale NULL y `-0.0` conserva el signo. `power` devuelve `DOUBLE`. Un resultado no finito sale NULL. Una base NULL elevada a `0` es `1.0`. `pow` no existe en 10.1.0. `ln` devuelve `DOUBLE`. Un negativo sale NULL. `ln(0)` es infinito negativo: se ordena antes que los finitos y se imprime como NULL. `log` es el logaritmo en base 10 y sigue las mismas reglas. `CHAR` 0 no entra en `count`, `min`, `max`, `sum` ni `avg`. `sum` y `avg` de texto no convertible fallan.
